\section{PENDAHULUAN}
Pendeteksian logam berat, khususnya Kadmium ($Cd^{2+}$), memiliki urgensi yang tinggi di bidang pemantauan kualitas lingkungan karena toksisitasnya yang fatal bagi makhluk hidup. Metode deteksi elektrokimia seperti \textit{Cyclic Voltammetry} (CV) banyak dipilih karena sensitivitasnya yang baik serta biaya pengoperasian yang lebih murah. Dalam eksperimen ini, dataset CV diekstraksi dari dua instrumen: sensor \textbf{LC (LecSens)} yang merupakan alat rakitan mandiri (custom) dan sensor \textbf{PS (EmStat4)} yang merupakan alat komersial standar industri\cite{dosen}. 

Dataset yang digunakan dikumpulkan secara sistematis dengan pengulangan tinggi untuk memastikan validitas statistik. Mencakup total 300 file pengukuran per alat (15 variasi konsentrasi $\times$ 50 repetisi per konsentrasi). Variasi tingkat konsentrasi berada di kisaran sangat rendah hingga tinggi (0, 2, 4, 6, 8, 10, 20, 40, 80, 100, 200, 400, 600, 800, 1000 ppm). Setiap file rekaman juga mencakup 10 siklus pindai (scan) untuk melihat stabilitas elektrode, dimana umumnya scan ke-3 hingga ke-10 yang digunakan sebagai objek analisis utama karena kondisi pemukaan elektrode yang sudah lebih stabil.

\section{TUJUAN DAN METODE}
\textbf{Tujuan Penelitian:}
\begin{itemize}
    \item Melakukan \textit{preprocessing} untuk menghilangkan derau (noise) dan mengekstraksi fitur kunci dari kurva CV mentah menggunakan pendekatan \textit{Dual-Peak}.
    \item Membangun dan melatih model \textit{machine learning} tingkat lanjut\cite{sklearn} untuk memetakan respon instrumen menjadi luaran konsentrasi Kadmium.
    \item Mengevaluasi dan membandingkan ketepatan instrumen LC versus PS menggunakan visualisasi yang komprehensif.
\end{itemize}

\textbf{Metodologi Pemodelan:}
Target prediksi berupa nilai konsentrasi ppm awalnya sangat timpang persebarannya. Oleh karena itu, target di-\textit{transform} terlebih dahulu menggunakan logaritmik $\log_{10}(\text{ppm} + 1)$ untuk meratakan distribusi \textit{residual} model. Metodologi regresi yang digunakan mencakup 15 arsitektur komparasi: model baseline linear, tree-based ensembles yang telah di-tuning via Optuna\cite{optuna} seperti XGBoost\cite{xgboost} dan CatBoost, arsitektur Deep Learning CAFF kustom berbasi atensi (Cross-Attention) menggunakan PyTorch\cite{pytorch}, metode canggih Zero-Shot In-Context Learning melalui TabICLv2\cite{tabicl}, serta penumpukan stacking menggunakan meta-learner Ridge.

\section{IMPLEMENTASI CODINGAN}
Tahapan pemrosesan data, feature engineering, dan pemodelan dikembangkan di lingkungan Python. Beberapa komponen esensial yang memastikan keberhasilan akurasi dijelaskan sebagai berikut.

\subsection{Adaptive Baseline \& Feature Extraction}
Dalam mengekstraksi informasi puncak oksidasi (anodic), data arus listrik ($I$) dihaluskan terlebih dahulu untuk menghilangkan *noise* frekuensi tinggi, kemudian dihitung selisihnya terhadap garis dasar (*baseline*). Baseline dihitung secara adaptif dengan mengambil persentil ke-5 dari kurva. Area di bawah kurva dikalkulasi dengan aturan integrasi Trapezoidal.

\begin{lstlisting}[language=Python, caption=Potongan Kode Feature Engineering Dual-Peak]
# Penghalusan Sinyal dengan Savitzky-Golay
i_smooth = savgol_filter(i_raw, window_length=9, polyorder=3)

# Adaptive baseline 5th percentile
background = np.percentile(i_smooth, 5)
i_peak = i_smooth - background

# Integrasi Area di bawah kurva (Trapezoidal Rule)
area = np.trapz(i_peak, v_raw)

# Ekstraksi titik puncak absolut (Ip) dan voltase (Ep)
idx_peak = np.argmax(i_peak)
ip_val = i_peak[idx_peak]
ep_val = v_raw[idx_peak]
\end{lstlisting}

\subsection{Log Transform dan Validasi Silang}
Untuk menghindari model bias terhadap angka konsentrasi masif (seperti 1000 ppm), *target variable* diubah logaritmik. Pemisahan *train/test* menggunakan *Stratified 5-Fold* yang menjamin distribusi *ppm* selalu merepresentasikan populasi asli di setiap iterasi pelatihan.

\begin{lstlisting}[language=Python, caption=Transformasi Logaritmik dan Stratified K-Fold]
# Transformasi Logaritmik pada Target PPM
y_log = np.log10(y_ppm + 1)

# Stratified 5-Fold Cross Validation
skf = StratifiedKFold(n_splits=5, shuffle=True, random_state=42)
for train_idx, val_idx in skf.split(X_scaled, labels_ppm):
    # Training process here...
\end{lstlisting}

\subsection{Ensemble Stacking Regressor}
Model tingkat lanjut dirangkai menggunakan arsitektur \textit{Stacking}. Model-model pohon yang sudah di-*tuning* via Optuna digabungkan prediksinya melalui *meta-learner* Ridge Regression untuk mengkoreksi *error* antar model *base*.

\begin{lstlisting}[language=Python, caption=Arsitektur Stacking Regressor]
from sklearn.ensemble import StackingRegressor
from sklearn.linear_model import Ridge

# Arsitektur Stacking dengan Ridge Meta-Learner
base_estimators = [
    ('XGB', best_models['XGBoost_Tuned']),
    ('CatBoost', best_models['CatBoost_Tuned']),
    ('LightGBM', best_models['LightGBM_Tuned'])
]

stacking_model = StackingRegressor(
    estimators=base_estimators,
    final_estimator=Ridge(alpha=1.0),
    cv=5,
    n_jobs=None
)
\end{lstlisting}

\section{KESIMPULAN}
Penelitian ini berhasil menyimpulkan keunggulan \textbf{sensor rakitan LC (LecSens)} dibandingkan instrumen komersial EmStat4 (PS). 
\begin{enumerate}
    \item \textbf{Performa Superior:} Instrumen LC mampu menembus skor determinasi $R^2$ hingga di atas 0.94 menggunakan metode XGBoost dan TabICLv2.
    \item \textbf{Stabilitas Signal:} Penilaian stabilitas (*boxplot* antar *fold*) memperlihatkan bahwa rasio S/N (*Signal to Noise*) dari LC memfasilitasi algoritma regresi untuk belajar secara optimal.
    \item \textbf{Akurasi Rentang Rendah:} Kemampuan sensor LC dalam mendeteksi konsentrasi renik (0-10 ppm) terlihat secara jelas pada inspeksi plot residual, yang menjadikannya *cost-effective solution*.
\end{enumerate}
